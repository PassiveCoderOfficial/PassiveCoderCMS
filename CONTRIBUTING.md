# Contributing to Passive Coder CMS

Thank you for helping. A few rules keep things simple:

1. **Sign the CLA once.** Before your first pull request is merged, accept the [Contributor License Agreement](CLA.md). Our CLA check asks you to post one comment on the pull request. Companies sign the entity form instead.
2. **Open an issue first** for anything larger than a small fix, so we can agree on the approach before you spend time on it.
3. **One change per pull request**, with a clear description and screenshots for anything visible.
4. **Keep it working:** `npx tsc --noEmit` and the tests must pass.
5. **No secrets** (keys, passwords, client data) in code, tests or screenshots.
6. **Report security problems privately** by email, not in a public issue.

By contributing you agree that your contribution may be distributed under the AGPL v3 and under Passive Coder's commercial licences, as the CLA describes.
