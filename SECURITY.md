# Security policy

## Reporting a problem

If you find a security problem in Passive Coder CMS, please tell us privately:

**Email: contact@passivecoder.com** with the subject "Security report".

Do not open a public issue, pull request or discussion for it, and do not
share details publicly until a fix has been released.

Please include:

- what the problem is and what an attacker could do with it;
- the steps to reproduce it (a small example helps);
- the version or commit you tested;
- how to reach you.

## What to expect

- We aim to confirm that we received your report within 3 working days.
- We will tell you whether we can reproduce it and what we plan to do.
- When a fix is released we will credit you, unless you ask us not to.

## Scope

This policy covers the code in this repository. For a problem on the hosted
service at passivecoder.com, use the same address.

Please do not test against sites you do not own, do not access other
people's data, and do not run tests that degrade a live service.

## Supported versions

Security fixes are made on the latest release. Please update before
reporting, if you can.
